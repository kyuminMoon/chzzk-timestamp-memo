# 스토어 등록 정보 (복사해서 붙여 넣기용)

Chrome 웹 스토어 개발자 대시보드의 각 칸에 그대로 넣을 수 있게 정리했습니다. Edge 애드온(Partner Center)도 거의 같은 칸을 씁니다.

## 패키지

- 올릴 파일: `dist/chzzk-memo-extension-<버전>.zip` (`python build.py`로 만듦)
- 새 버전을 올릴 때는 `src/manifest.json`의 `version`을 먼저 올리세요 (예: 1.0.0 → 1.0.1). 같은 버전은 다시 올릴 수 없습니다.

## 스토어 등록정보 (Store listing)

- **이름**: 합방 타임스탬프 메모 (치지직용) — manifest의 name이 그대로 쓰입니다
- **요약**: manifest의 description이 그대로 쓰입니다
- **카테고리**: 생산성 → 도구 (Tools)
- **언어**: 한국어
- **아이콘**: `src/icons/icon128.png` (zip 안에도 들어 있음)
- **캡처화면 (1280×800, 24비트 PNG)**: `store/screenshots/` 의 4장을 이 순서로
  1. `1-live-memo-write.png` — 라이브 메모 쓰기 (주소 추가 → 체크 → 메모 쓰고 Enter)
  2. `2-live-memo-copy.png` — 스트리머별 복사 → 다시보기 댓글에 붙여넣기
  3. `3-replay-find.png` — 실제 시각으로 다시보기마다 재생 위치 찾기
  4. `4-replay-copy.png` — 여러 줄 한 번에 저장 · 같은 형식으로 복사
  - 화면 속 스트리머 · 방송은 모두 지어낸 예시입니다 (실제 채널 아님).
- **작은 프로모션 타일 (440×280)**: `store/promo-small-440x280.png`
- **성인용 콘텐츠**: 끔

### 상세 설명

```
치지직 합방을 보다가 노래나 명장면이 나오면 메모를 한 번만 쓰세요. 체크해 둔 스트리머마다 "그 순간이 각자 방송의 몇 분 몇 초인지"를 따로 계산해 저장합니다.
방송이 끝난 뒤 스트리머를 골라 복사하면, 그 스트리머의 다시보기 댓글에 바로 붙여 넣을 수 있는 타임스탬프 목록이 만들어집니다.

00:24:56 [하늘빛] - 오프닝 인사 & 첫 곡
00:46:56 [바다소리] - 신청곡 1
01:13:56 [구름이, 별하나] - 듀엣

설치한 뒤 브라우저 툴바의 아이콘을 누르면 메모 화면이 새 탭으로 열립니다.

※ 치지직(CHZZK)의 비공식 확장 프로그램이며, 소스 코드를 GitHub에 공개한 오픈소스 프로젝트입니다.

■ 라이브 메모 사용 방법
1. 합방 중인 스트리머들의 치지직 라이브 주소(또는 채널 주소)를 방송 목록에 추가합니다.
2. 메모할 방송에 체크합니다. (모두 체크 · 모두 해제 버튼이 있고, 체크 상태는 다음에 열어도 유지됩니다)
3. 장면이 나오면 메모를 쓰고 Enter. 메모를 쓰기 시작한 순간의 시각으로 저장됩니다.
4. 방송이 끝나면 저장한 메모에서 스트리머를 골라 "복사"를 누르고, 다시보기 댓글에 붙여 넣습니다.

■ 라이브 메모 기능
• 한 번의 메모로 체크한 모든 방송의 위치를 동시에 저장
• 스트리머별 · 방송별 복사, 줄마다 실제 시각을 함께 붙이는 복사
• 싱크가 맞지 않으면 복사할 때 전체 시간을 ±n초 보정
• 저장한 메모의 내용 · 시간 수정, 같이 저장한 방송 전체를 같은 초만큼 한 번에 보정
• 복사한 내용을 붙여 넣고 다듬은 뒤 다시 복사하는 "댓글 다듬기" 칸
• 방송을 껐다 다시 켠 스트리머도, 이전 방송을 메모 화면에서 확인해 둔 경우 그 방송 기준으로 계산

■ 다시보기 시간 찾기 사용 방법
1. 치지직 다시보기 링크를 한 줄에 하나씩 넣고 추가합니다. (여러 개를 한 번에 넣을 수 있습니다)
2. 실제 시각(한국 시간)을 초까지 입력하고 찾기를 누릅니다. 예: 26-11-21 21:25:30
3. 체크한 다시보기마다 그 시각의 재생 위치가 나옵니다.
4. 메모를 쓰고 저장하면 체크한 결과에 한 번에 저장됩니다. 체크는 그대로 남아 다음 메모도 바로 저장할 수 있습니다.

■ 다시보기 시간 찾기 기능
• 라이브 메모와 같은 "HH:mm:ss 메모" 형식으로 다시보기별 복사
• 라이브 메모의 "실제 시간 포함 복사" 결과를 붙여 넣으면 여러 줄을 한 번에 다시보기 위치로 바꿔 저장 (이미 저장된 같은 메모는 건너뜀)
• 다시보기마다 시간 보정 값을 따로 설정

■ 개인정보
• 메모는 이 브라우저 안에만 저장되며 어디로도 전송되지 않습니다. 광고나 사용 기록 수집이 없습니다.
• 방송 시작 · 종료 시각과 다시보기 정보만 치지직에서 조회합니다. 로그인 정보는 사용하지 않습니다.
• "백업 · 가져오기" 탭에서 메모를 파일로 내려받고 다시 가져올 수 있습니다. 확장 프로그램을 삭제하면 메모도 함께 지워지니 가끔 백업해 두세요.

■ 참고
• 방송 위치는 "실제 시각 − 방송 시작 시각 − 4초(시청자 화면 지연)"로 계산합니다. 보는 환경에 따라 몇 초 차이가 날 수 있으니 조금 앞부분부터 확인하세요.
• 성인 인증이 필요하거나 비공개인 다시보기는 정보를 가져올 수 없습니다.

■ 오픈소스
• 소스 코드 전체가 GitHub에 MIT 라이선스로 공개되어 있습니다. 어떤 정보를 어디에서 가져오는지 코드로 직접 확인할 수 있습니다.
• 버그 제보, 기능 제안, 개발 기여 모두 환영합니다.
• https://github.com/kyuminMoon/chzzk-timestamp-memo

■ 안내 (면책 조항)
• 이 확장 프로그램은 개인이 만든 비공식 도구로, 네이버(NAVER) 및 치지직(CHZZK)과 관련이 없으며 이들이 만들거나 승인하지 않았습니다.
```

## 개인정보 보호 관행 (Privacy practices)

### 단일 목적 (Single purpose)

```
치지직 방송을 보면서 쓴 메모를 각 스트리머 방송의 재생 위치(타임스탬프)로 바꿔 저장하고, 타임스탬프 댓글로 복사하는 도구입니다.
```

### 권한 사유 (Permission justification)

- **storage**
  ```
  사용자가 등록한 채널 목록과 메모를 브라우저 안(chrome.storage.local)에 저장하기 위해 사용합니다. 외부로 전송하지 않습니다.
  ```
- **호스트 권한 `https://api.chzzk.naver.com/*`**
  ```
  사용자가 직접 추가한 채널과 다시보기의 이름 · 제목, 방송 시작 · 종료 시각, 다시보기 길이를 치지직(api.chzzk.naver.com)에서 조회하기 위해 사용합니다. 이 시각으로 메모의 방송 위치를 계산합니다. 로그인 정보(쿠키)는 보내지 않으며, 다른 사이트에는 접근하지 않습니다.
  ```

### 원격 코드 (Remote code)

- "아니요, 원격 코드를 사용하지 않습니다" 선택. 모든 스크립트가 패키지 안에 있고, 외부에서 받는 것은 JSON 데이터뿐입니다.

### 데이터 사용 (Data usage)

- 수집하는 데이터 항목: **웹사이트 콘텐츠만 체크**
  - Google FAQ는 기기 안에만 저장하는 데이터도 공개 대상이라고 안내합니다 (User Data FAQ: "even when data is processed or stored locally").
  - 이 확장은 치지직에서 조회한 채널 이름, 방송 · 다시보기 제목과 시각, 다시보기 링크를 저장하므로 "웹사이트 콘텐츠"에 해당합니다.
  - 나머지 항목은 체크하지 않습니다. 브라우저 방문 기록, 클릭 · 키 입력, 위치, 로그인 정보를 읽지 않고, 메모는 사용자가 쓴 글을 기기 안에 저장할 뿐 다른 사람과 주고받는 메시지가 아닙니다.
- 아래 세 가지 인증에 모두 체크:
  - 승인된 사용 사례 외의 목적으로 사용자 데이터를 판매하거나 전송하지 않음
  - 단일 목적과 관련 없는 목적으로 사용자 데이터를 사용하거나 전송하지 않음
  - 신용도 판단이나 대출 목적으로 사용자 데이터를 사용하거나 전송하지 않음

### 개인정보처리방침 URL

- 기기 안에만 저장하더라도 사용자 데이터를 다루므로 **필수**입니다 (User Data FAQ: "all Products that handle user information to post a privacy policy").
- `store/privacy-policy.md`의 내용을 공개 웹페이지에 올리고, 그 주소를 넣으세요.

- 대시보드에 체크한 항목, 개인정보처리방침, 실제 동작이 서로 다르면 정책 위반으로 거부될 수 있으니 세 가지를 맞춰 두세요.
